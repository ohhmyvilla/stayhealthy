# Stay Healthy

A simple nutrition tracker that runs in your browser. No install, no server.

## Features

- Log foods for **Breakfast, Lunch, Dinner and Snack**
- Daily targets: calories plus a % split for carbs, protein and fat (grams are calculated for you)
- See what's left for each macro, and today's calorie split next to your target split
- Leave kcal blank and it's worked out from macros (4 kcal per g carbs and protein, 9 per g fat)
- Log **body weight** with a 30-day trend
- Light and dark mode, works on phones

## Use it

Open `index.html` in any browser. Entries are saved in that browser on that device.
